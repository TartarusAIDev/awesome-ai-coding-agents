# Security Policy

This repository is a dataset, a README, and small standard-library scripts — it
runs no service and ships no package. The realistic risks are a malicious link
or a bad-faith data change.

- **A listed link looks malicious or was hijacked** — please report it
  privately via **Security → Report a vulnerability** on this repo, or email
  **team@tartarusai.dev**. Don't open a public issue that points more people at
  it.
- **A problem in the scripts** (`scripts/*.py`) — same channel.

For ordinary corrections (wrong license, dead link, outdated field), a normal
issue or PR is perfect.
